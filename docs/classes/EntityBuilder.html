    Class EntityBuilder

    EntityBuilder provides a fluent API for creating entities with components

    Example

    const player = createEntityBuilder(world)
      .with('Position', { x: 10, y: 10 })
      .with('PlayerControlled', {})
      .with('Glyph', { char: '@', color: [255, 255, 255] })
      .build();
